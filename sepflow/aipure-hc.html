AIpure-HC

AIpure-HC is a fully configured chromatography system built around PEEK plunger pumps, high-pressure valves rated to 20 MPa, four titanium pressure sensors and a 200–800 nm diode array detector. Inline conductivity, temperature-compensated pH and an automated sample pump with an 8-channel sample inlet valve support unattended loading of multiple large-volume samples. The system is run by ChromX Chromatography Workstation software, which complies with FDA 21 CFR Part 11.

Key features
  • 8-channel inlet valves in all-PEEK construction with an integrated ultrasonic bubble sensor
  • Four titanium-alloy pressure sensors imported from the USA (pump S, system, pre-column and post-column), 0–20 MPa range, with high sensitivity and stability
  • High-pressure 5-position column valve with working pressure up to 20 MPa, supporting bypass, forward and reverse flow modes
  • High-pressure injection valve rated to 20 MPa, with sample pump loading, feed, waste and sample loading modes
  • pH valve supporting online, bypass and calibration modes
  • High-precision pH electrode with a 1–14 range
  • Conductivity monitoring from 0–999 mS/cm with automatic temperature compensation; titanium alloy and PEEK flow cell
  • Sample pump and sample inlet valve for automatic loading of multiple large-volume samples
  • Diode array detector imported from Europe: 200–800 nm range, low noise and flat baseline, with four wavelength bands adjustable simultaneously
  • PEEK plunger pumps with double cam, double plunger and double pump head design; phase compensation suppresses pump pulsation
  • Pump self-washing function prevents salt precipitation; working pressure over 20 MPa; ruby and sapphire biocompatible materials
  • ChromX Chromatography Workstation software: easy to learn and use, and compliant with FDA 21 CFR Part 11
  • Column information library tracks column history and performance parameters in real time
  • System control, manual and automatic methods, scouting, method queue, data analysis, report generation, audit trail and user management
  • Automatic and manual database backup with data recovery
  • Free lifelong remote software upgrades, including the upcoming DOE function
  • Real-time control and monitoring of system operation and data, real-time logging, real-time chromatogram recording and historical view
  • Buffer management with real-time monitoring of buffer usage
